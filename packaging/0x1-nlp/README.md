# 0x1NLP

0x1NLP provides Indonesian natural language preprocessing. Installing `0x1-nlp` provides the `ox1nlp` import and installs the `nahiarhdNLP` library it uses.

```bash
pip install 0x1-nlp
```

```python
from ox1nlp import DatasetLoader, Pipeline
```

Existing projects can continue installing and importing `nahiarhdNLP`. For library submodules, keep importing from `nahiarhdNLP`.

[Documentation and examples](https://github.com/raihan0x1/0x1-nlp#readme)
