# 0x1NLP

0x1NLP uses the `nahiarhdNLP` distribution for Indonesian natural language preprocessing. Installing `0x1-nlp` installs that distribution and uses the same Python API.

```bash
pip install 0x1-nlp
```

```python
from nahiarhdNLP.preprocessing import Pipeline
```

Existing projects can continue installing `nahiarhdNLP` directly.

[Documentation and examples](https://github.com/raihan0x1/nahiarhdNLP#readme)
